# App Icons

## Required Icons

Place the following icon files in this directory:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## How to Generate

### Quick Method:
1. Go to https://www.pwabuilder.com/imageGenerator
2. Upload a 512x512 source image
3. Download and extract the icon pack
4. Copy all icons to this folder

### Manual Method:
1. Create a 512x512 design with your logo
2. Export at each size listed above
3. Save as PNG with transparency

## Design Guidelines

- **Theme**: Teal (#14b8a6) background
- **Icon**: Travel-themed (airplane, compass, globe)
- **Style**: Minimalist, modern
- **Safe Zone**: Keep important content in center 80%

See PWA_SETUP_GUIDE.md for detailed instructions.
