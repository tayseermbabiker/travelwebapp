# App Screenshots

## Required Screenshots

Place the following screenshot files in this directory:

- **home.png** (1280x720) - Desktop/tablet home screen
- **mobile-home.png** (750x1334) - Mobile home screen

## How to Create

### Method 1: Browser Screenshots
1. Build and run the app: `npm run build && npm start`
2. Open in browser at target resolution
3. Take screenshot of home page
4. Crop to exact dimensions
5. Save to this folder

### Method 2: Responsive Design Mode
1. Open DevTools → Toggle device toolbar
2. Set custom dimensions (1280x720 or 750x1334)
3. Navigate to home page
4. Take screenshot
5. Save to this folder

## Purpose

Screenshots are used in:
- Browser install prompts
- App store listings (if applicable)
- Social media previews
- PWA manifest

## Optional

Screenshots are optional but recommended. They help users preview your app before installing.

See PWA_SETUP_GUIDE.md for more details.
