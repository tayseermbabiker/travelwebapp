3. SET UP MONGODB ATLAS (Optional - for data persistence)
   Priority: LOW (app works without it)
   Time: 20 minutes

   Why: Store itineraries, track analytics, monitor affiliate clicks

   Current State:
   - App uses sessionStorage (data lost on browser close)
   - MongoDB code is ready, just needs connection URI

   Steps:
   - Go to https://www.mongodb.com/cloud/atlas
   - Create free account (if needed)
   - Create new cluster (M0 Free Tier - 512MB storage)
   - Create database user (username + password)
   - Whitelist IP addresses (0.0.0.0/0 for all IPs)
   - Get connection string (looks like: mongodb+srv://user:pass@cluster.mongodb.net/)
   - Go to Vercel dashboard > Project Settings > Environment Variables
   - Add: MONGODB_URI = your_connection_string
   - Redeploy (automatic)

   What MongoDB Enables:
   - Persistent itinerary storage
   - View count analytics
   - PDF download tracking
   - Affiliate click tracking
   - Commission monitoring
   - Admin dashboard data

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Problem: "OpenAI API error"
Solution:
- Check API key is valid
- Check OpenAI account has credits
- Check usage limits not exceeded

Problem: "Function timeout"
Solution:
- Reduce AI response size
- OR upgrade to Vercel Pro
- OR optimize prompt

Problem: "MongoDB connection error"
Solution:
- This is normal if MONGODB_URI not set
- App will use sessionStorage instead
- Only fix if you want MongoDB features

Problem: "Build fails on Vercel"
Solution:
- Check Vercel build logs
- Ensure all dependencies in package.json
- Check TypeScript errors locally first: npm run build

Problem: "Itinerary not displaying"
Solution:
- Check browser console for errors
- Verify sessionStorage has data
- Check API response in Network tab
